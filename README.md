# research_vis vault

This repository is data, not code. It is written by the research_vis app (phone/laptop
browser) and by the `rvis` CLI on the laptop. Everything is plain JSON / Markdown / WebP,
readable without the app.

- `papers/<id>/`  parsed papers (bundle.json, figures/, pages/, corrections.json)
- `notes/<id>/`   your annotations, one JSON file each (+ voice notes)
- `notes/<id>.md` readable notes per paper (regenerated by `rvis sync`)
- `state/<id>.json` reading status and position
- `inbox/`        papers waiting to be ingested by `rvis sync`

Keep this repository private: it contains copies of papers for personal use.
